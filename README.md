# 🎈 تعلم الإنجليزي للأطفال

صفحة ويب بسيطة لتعليم الأطفال الإنجليزي مع النطق الصوتي.

## الأقسام
- 🔤 الحروف (A–Z مع كلمة لكل حرف)
- 🔢 الأرقام (1–10)
- 🎨 الألوان
- 🐾 الحيوانات
- 🍎 الفواكه
- 🙂 أعضاء الجسم
- 📅 الأيام و 🗓️ الشهور
- 🔺 الأشكال و 👕 الملابس
- 👨‍👩‍👧 العائلة
- 👋 التحيات
- 🏆 اختبار: يسمع الطفل الكلمة ويختار الصورة الصحيحة، ويجمع نجوم (ويقدر يحاول مرة ثانية إذا أخطأ)

## التشغيل
افتح ملف `index.html` في المتصفح. الأصوات مسجلة مسبقاً في `sounds.js` فتشتغل على الجوال وبدون إنترنت.
