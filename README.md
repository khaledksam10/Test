# 🎈 تعلم الإنجليزي للأطفال

صفحة ويب بسيطة لتعليم الأطفال الإنجليزي مع النطق الصوتي.

## الأقسام
- 🔤 الحروف (A–Z مع كلمة لكل حرف)
- 🔢 الأرقام (1–10)
- 🎨 الألوان
- 🐾 الحيوانات
- 🍎 الفواكه
- 👨‍👩‍👧 العائلة
- 👋 التحيات
- 🏆 اختبار: يسمع الطفل الكلمة ويختار الصورة الصحيحة

## التشغيل
افتح ملف `index.html` في المتصفح (يفضل Chrome أو Edge لأفضل نطق). لا يحتاج إنترنت أو تثبيت.
